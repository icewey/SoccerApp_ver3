# アニメーション再生ポリシー

このプロジェクトのキャラクターモーションに関する取り決め。**新しいワンショット動作を追加するときは必ずこのルールに従うこと。**

## 原則: ワンショットモーションは最後まで再生する

キック・パス・タックル・スピン・GKのキャッチ/ダイブ/スロー等の「一度きりの動作」アニメは、**途中で別アニメに差し替えず、clip の全長を再生しきる**。

ゲーム上のイベント（ボールの所有権が移った、ボールを奪った/奪われた、拾った等）が起きても、それを理由に再生中のモーションを打ち切らない。見た目が一瞬でリセットされ「モーションが無い」ように見えるのを防ぐため。

### 実装ルール

1. **動作フラグ（`isKicking` / `isTackling` / `isPassing` / `isSpinning` / 敵の `enemyTackling` 等）は、clip の再生完了で解除する。**
   - 第一の解除経路: `AnimationMixer` の `'finished'` イベントリスナ。
   - 第二の解除経路（保険）: clip 全長に合わせたタイマー（例 `tackleTimer = clips['tackle'].duration + 0.1`）。`'finished'` を割り込みで取りこぼしてもフラグが固着しないようにするためのフォールバックであり、**モーションを短く切るための値にしてはいけない**。

2. **ゲームイベントでフラグを `false` にして動作を中断しない。**
   - 例: タックルでボールを奪取しても `isTackling` / `enemyTackling` はそのまま。所有権だけ移し、モーションは流し切る。

3. **「移動（前進ランジ等）」と「モーション再生」は別タイマーで分離してよい。**
   - モーションは全長再生しつつ、前進だけを早めに止めたい場合は専用タイマーを使う（例 `tackleLungeTimer = TACKLE_LOCK`）。
   - これは原則1に反しない。あくまで *移動* を止めるだけで、*アニメ* は止めない。

4. **操作ロック中の入力差し替え。**
   - 動作フラグが立っている間は `getDesiredAnim()` が `null` を返し、移動アニメで上書きしない。

### 例外

- **ハードな状態遷移**（ゴール演出開始 `isGoalScene`、ゲームリセット、GKがボールをキャッチして即 `hold` 等）では、`mixer.stopAllAction()` で全モーションを止めてよい。これは「次のシーンへ切り替える」ための停止であり、ワンショット動作の途中打ち切りとは区別する。
- **マルチプレイ**では相手キャラの硬直やモーション完了をローカルで完全再現できないため、見た目の同期は best-effort とする。

## 関連挙動

- **ボールを奪われた側のスタン**: タックルで所有権が移ったら、奪われた側は `STUN_TIME`（約0.6秒）硬直し、頭上に `‼️`（`spawnStunMark`）を表示する。奪った側のタックルモーションは上記ポリシー通り最後まで再生される。
